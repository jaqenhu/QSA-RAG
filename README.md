## 管理员账号（2026-10-21）

已接入首个本机管理员账号 `admin`。首次启动在数据库预建待激活账号；浏览器打开本机地址后设置 12–128 字符密码并确认，设置成功即进入工作台。没有默认密码，也没有通过聊天或文件交付初始密码。激活后初始化入口关闭，重启不会覆盖密码。

登录前仅加载登录界面，全部业务接口（包括知识库、模型、任务、下载和修改）均校验管理员会话。密码用带随机盐的 scrypt 保存；会话凭据只放在 HttpOnly、SameSite=Strict Cookie 中，数据库仅存其哈希，8 小时后过期，退出立即失效。登录失败限流跨重启保留；密码和会话凭据不写入日志、浏览器存储或任务快照。

本轮仅开通一个管理员，管理员使用已有全部业务数据。没有普通成员注册或新增入口，也未实现多人任务隔离与排队。服务继续仅监听本机，不开放局域网，不调整防火墙，不安装证书或开机服务。当前 HTTP 仅用于本机回环；未来开放局域网时须部署 HTTPS 并调整可信地址校验，不能只改监听地址。

隔离测试账号通过真实初始化/登录接口生成，不提供绕过鉴权的环境变量。运行 `tests/auth-browser-smoke.mjs` 可验证初始设置、登录、退出、刷新和会话过期，测试不会修改真实管理员密码或调用云模型。

## 本地运行

需要 Node.js 24 或更新版本、Python 3.10 或更新版本、Windows 当前用户环境。首次安装依赖：

```powershell
python -m pip install -r requirements.txt
npm ci
```

在项目目录启动：

```powershell
npm run dev
```

访问 `http://127.0.0.1:4173/#knowledge-preview`。直接打开 HTML 无法使用真实业务接口，页面会提示启动本地服务。

如果 4173 已被占用，可在当前 PowerShell 会话改用其他端口：

```powershell
$env:PORT = '4174'
npm run dev
```

当前开发验收服务使用 `http://127.0.0.1:4173`；启动时输出的地址为准。可用 `QSA_PYTHON` 指定 Python 可执行文件，`QSA_DATA_DIR` 指定独立的数据目录。服务只监听本机回环地址。

保存密钥使用 Windows 当前用户 DPAPI。请从正常 Windows 用户终端启动服务；受限沙箱可能无法访问系统密钥目录。同一数据目录只允许运行一个服务，重复启动会拒绝，避免影响正在进行的训练。

- 整项没有任何成功生成的条目时显示“生成失败”；有已生成结果但部分条目调用失败时，显示浅黄色“生成成功，部分需审核”。全部条目处理成功则显示“生成成功”；部分证据或无相关信息属于已完成判断。

## 首次配置百炼

1. 打开“模型配置”，选择阿里云百炼，分别添加生成与向量模型。页面预填 `qwen-plus` 和 `text-embedding-v4`，模型 ID 可以修改。
2. 确认地址对应密钥地域。预填北京旧域名 `https://dashscope.aliyuncs.com/compatible-mode/v1`，也支持控制台提供的业务空间专属域名；新加坡使用对应地域地址。
3. API Key 只在本机页面填写。保存后，在列表点击“测试”，向量模型通过后即可用于训练。弹窗测试仅验证当前输入，保存后仍需验证已保存配置。
4. “知识库训练”选择工作表和已通过测试的向量模型，点击“开始训练”。只发送所选有答案问答的章节、问题与自评说明至所配向量服务；不发送原 Excel 文件或 D 列旧备注。
5. 完成后在“检索验证”输入真实审核问题，检查原文与来源。重排可选，百炼预填 `qwen3-rerank`，不使用时无需配置。

生成和向量调用使用 AI SDK 的 OpenAI 兼容适配器；百炼重排使用官方 DashScope HTTP 路径。现有域名与专属域名、参数和批量限制依据 [百炼文本生成](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)、[向量接口](https://help.aliyun.com/zh/model-studio/text-embedding-synchronous-api)、[重排接口](https://help.aliyun.com/zh/model-studio/text-rerank-api) 核对。其他服务商保留兼容配置入口，尚未逐项进行真实云端验证。

## 检索与索引规则

每批最多 8 条问答；完整文本参与向量化，超出模型输入限制时明确失败，不静默截断。缺少自评说明的记录保留在知识库，但不参与索引。

增量更新按实际向量化文本（章节、问题、自评说明）的内容哈希复用同项目、同向量模型身份和解析规则的向量；未变化的内容即使原始行移动，也关联至新版本记录。仅重算新增或修改内容；删除记录不进入新索引，旧索引保留供历史引用。全部复用时仍进行一次查询向量校验，不代表零 API 调用。

推荐默认值：向量 TopK=20、BM25 TopK=20、RRF k=60、重排候选上限=40、重排 TopN=8、重排阈值=0.5。先两路独立召回，按记录 ID 合并去重，再按融合排名截取重排候选；重排后按阈值过滤，最多返回 TopN 条，不补入低于阈值的结果。

关键词检索采用中文双字片段与英文/数字词的 BM25，关键词分数映射为 `BM25 / (BM25 + 3)`；向量分数为非负余弦相似度。默认 RRF 使用 `Σ 1/(60+名次)`；可切换至原加权方案 `0.65 × 向量 + 0.35 × 关键词`。RRF 分数不使用 0–1 相似度阈值过滤。启用重排只使用独立重排阈值；关闭重排后默认最多返回 8 条，向量、关键词及加权融合可使用相似度阈值。分数和阈值不代表证据充分或事实正确。

在“知识库训练 → 检索设置”选择参数并点击“保存检索设置”，保存后用于新自评，不调用云端模型或重算向量。检索验证区支持临时调参，不自动保存到正式设置。每个知识库独立保存并校验版本/修订冲突；每个自评任务冻结检索参数，后续修改不影响运行中任务，失败重试也保留原参数。旧任务未保存新参数时，重试继续使用原加权融合、TopK=8、阈值=0.5。

## 数据位置与备份

默认业务数据位于 `.data/`：`qsa.sqlite` 保存项目、版本、记录与解析草稿，`files/` 保存上传文件副本。上传不会修改源文件。解析失败的文件会移除；解析成功但未确认的文件保留为草稿，不会出现在项目列表。草稿暂不自动清理。

备份前关闭本地服务，再复制完整 `.data/` 目录；恢复时也需关闭服务并恢复整个目录。该目录、密钥文件、日志及测试数据均已加入 `.gitignore`，不会通过静态页面路由暴露。

数据库保存模型元数据、加密密钥、索引向量、训练任务、输入行、自评执行、逐题结果和来源快照。DPAPI 密钥与 Windows 用户和机器绑定，复制数据库至其他用户或机器后需重新填写密钥。自评结果及任务记录不使用设计示例。当前任务可刷新恢复，历史结果可通过 `#supplier/<任务ID>` 只读回看。重试创建关联原任务的新执行并保留成功项；仅在原知识库版本和模型配置仍兼容时允许重试，同版本兼容索引重建不会阻止重试。

## 供应商自评与导出

1. 进入“供应商自评”，选择已建好索引的知识库，并上传 `.xlsx` 待填表。展开“待填表明细”核对工作表、原始行号、写入单元格和答案合并范围。
2. 选择已测试的生成模型。初次使用可选择“先验证前 5 项”，核对原文与覆盖情况后切换“全部问题”。点击“开始填表”会向所配服务发送该题和候选知识库问答，不发送完整原文件。
3. 逐题查看自评、缺少依据和原始 C 列说明。模型只能选择引用，答案正文采用核验后的原文提取；该限制减少无依据改写，但不能代替对证据适用性和覆盖完整度的核对。
4. 结束后可“重试失败项”。“导出表格”下载新副本。小范围验证的未选题写为“未生成（本次未选择）”，依据留空，不会冒充整表完成。

网页和 Excel 按“自评说明 → 依据 → 详细说明 → 来源”排列。“依据”只使用以下四种值：

- 可直接复用：详细说明为 `/`。
- 部分有依据：详细说明只列缺少依据的内容，自评说明不再附加这些缺失项。
- 无相关信息：详细说明为 `没有搜索到相关信息`。
- 调用失败：详细说明为 `调用失败`。

导出采用 OOXML 定点修改，保留未改动包部件的原始字节，原文件按 SHA-256 校验。普通单元格公式和命名范围随插列调整；输出答案按文本写入。宏、加密、受保护的待填工作表、跨越 C 列与其他列的答案合并、影响插列的跨工作表范围公式，以及带附加列又包含图表/结构化表等未支持情况会明确拒绝。当前真实文件已重读及预览核对，未在原生 Excel 中打开验收。

## 当前确认的业务规则
