# Provider brand marks

Original, unmodified brand SVGs from the LobeHub static icon library, pinned to `@lobehub/icons-static-svg@1.95.1` (MIT). The graphic for 火山引擎方舟 is the vendor's Volcengine mark; 智谱 GLM uses the Zhipu vendor mark.

`sources.json` records each upstream URL, exact package file and SHA-256. `LICENSE-LobeHub.txt` contains the upstream license. Brand names and marks identify their respective services; the static preview does not imply an active provider integration.

Eight brands: OpenAI, Bailian, Volcengine, Hunyuan, Zhipu, Kimi, DeepSeek and SiliconCloud. The custom compatible service retains a neutral settings icon.
