# User-provided UI images

These original PNG files were supplied by the user for this design revision. They are copied without image edits.

- `qsa-assistant.png`: image 1, upper-left brand/avatar.
- `knowledge-library.png`: image 2, supplier assessment knowledge workbook and knowledge preview project icon.
- `input-sheet.png`: image 3, supplier assessment input workbook.

CSS displays the whole image with a fixed aspect ratio. The avatar uses multiply blending to integrate its white background with the sidebar surface.
