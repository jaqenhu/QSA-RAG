# QSA 第 5–7 项开发与真实整表验收

日期：2026-10-19。范围：待填表导入、逐题证据自评、Excel 副本导出；不包含第 8 项完整历史列表或第 9 项增量索引。

## 实现与数据边界

- 供应商自评页已接入真实待填表上传和本地保存。展示实际文件名、工作表、问题数、C 列写入单元格及合并范围；不按 A 列是否有值筛选问题，不混入六条历史设计示例。
- 模型按题拆分要求，从候选记录的 C 列自评说明选取连续原文片段。程序验证候选记录 ID、原文包含关系和逐项状态后组合自评正文；不能以候选问题本身证明已执行。缺失要求与事实正文分开显示。当前采用原文提取，未开放不受约束的改写。
- 来源由程序写入知识库版本、Sheet、原始行与 C 单元格。原文快照、引用片段、输入行、模型元数据和逐题状态持久保存，不保存到浏览器存储，不包含密钥。
- 两题并发，每题完成即保存；提供停止和失败项重试。重试创建新执行并复制成功项，旧任务保留。刷新恢复当前任务；重启将中断行标失败，不自动发起云端调用。运行中禁止删除所用模型；知识库、索引或模型调用配置变化后停止混用。
- 百炼生成使用 AI SDK 7 的 `generateText` 和 `Output.json()`，实际兼容请求为 `response_format: {type: "json_object"}`，随后仍进行程序结构及引用验证。接口依据：[百炼结构化输出](https://help.aliyun.com/zh/model-studio/qwen-structured-output)。模型未按数组格式返回的无依据空引用规范为 `[]`；单条引用即使改为数组，也仍须核对 ID 和 C 列原文。

## 真实输入与生成

从原始用户输入.xlsx 重新解析出 183 项有效问题、7 组答案列合并，共涉及 24 项问题。范围为 C3:C5、C6:C7、C8:C11、C12:C16、C17:C18、C19:C23、C24:C26。程序按实际文件识别，不硬编码这些行或计数。

使用已配置且用户确认的实际模型 ID：生成 qwen-max，向量 text-embedding-v4（1024 维），重排 qwen3-rerank；知识库为知识库V2.xlsx v1 的 1,955 条可用索引。

先从真实网页运行前 5 项，得到 3 项完整依据、2 项部分依据、0 项失败。例如“质量手册是否经高层批准”没有直接依据，缺失项明确保留。之后执行全部 183 项，首轮为 108 项完整、38 项部分、25 项无信息、12 项失败。对失败项进行有限重试及格式修复，已完成的结果不重算。

最终当前任务 `a5029701-79fe-48f3-8d58-6a6aa19de702`：183/183 项处理结束，113 项完整依据、41 项部分依据、27 项无相关信息、2 项失败。剩余失败位于输入第 88、120 行，模型仍没有返回可核验的引用列表，系统保留失败状态与重试入口，未写入无法验证的自评事实。整个任务因仍有失败项而保持 `failed` 状态，不伪装整表成功。

逐项重新查询核对了最终结果的 420 处来源引用：记录 ID、原始 C 列全文、Sheet、行号、单元格及引用片段均匹配。重试前已完成结果的答案、状态和来源保持一致。该检查证明保存和来源映射一致，不证明模型对每个复合要求的覆盖判断已经人工确认；无相关信息也不表示整个知识库必然没有可用证据。当前检索采用混合 + 重排、Top K=8、阈值 0.5。

原始首轮报告为 `v13-real-checks.json`，最终重试报告为 `v13-retry-checks.json`。中间失败执行均保存在本机数据库，完整历史列表仍待第 8 项。

已通过网页“导出表格”生成 `outputs/2026-10-19/用户输入—自评结果.xlsx`。对 183 项逐题核对：C 列自评与页面一致，部分依据含缺失要求，失败项写失败信息；D 列来源标签与页面引用一致，无引用项明确标注。7 组答案合并均拆开，其他合并保留，所有 A/B 输入内容和非问题 C 单元格值保持一致。

导出定点修改 OOXML，不重建整个工作簿。实际变动部件仅为审核表 XML 与 styles.xml：答案列宽调整为 60，新增来源列宽为 48，行高按问题、答案与来源适配；对原先未换行的答案样式追加克隆，旧样式和字体/边框等其他样式内容保持不变。其余包部件逐字节一致，原始工作簿 SHA-256 未变。结果以文本写入，不执行答案中的公式字符。隔离样本另核对了既有公式及其他工作表保留。

实际文件已由 openpyxl 重新打开核对，并用表格渲染器预览 A1:D8；未启动本机 Microsoft Excel 应用，不宣称做过原生 Excel 应用完整检查。详见 `v13-export-checks.json` 和 `v13-excel-final.png`。
