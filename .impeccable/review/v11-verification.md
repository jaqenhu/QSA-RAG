# QSA v0.3 模型配置、索引与检索验收

日期：2026-10-19。范围：开发计划第 3–4 项。

## 已实现

- 真实模型配置、分类默认设置、编辑与删除；Windows 当前用户 DPAPI 加密保存密钥，前端与训练快照不回显密钥或密文。
- 生成、向量、重排分别执行对应接口测试。首次适配百炼，兼容地址支持旧 DashScope 域名及业务空间专属域名；重排使用官方 DashScope HTTP 格式。
- 逐行有答案问答入库引用、分批向量化、实际进度与阶段、取消、服务重启中断恢复；完整校验后发布索引。
- 关键词、向量、混合检索及可选重排，支持 Top K 与阈值；返回原文、记录 ID、版本、Sheet、原始行号和单元格。
- 知识库版本、向量模型 ID/地址/维度/类型变化或规则版本不匹配时索引失效；失败和取消不替换原可用索引；同一数据目录拒绝重复启动服务。
