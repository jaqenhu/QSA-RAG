## 交付行为

- 任务记录改用真实已结束执行，提供状态/日期/搜索/分页、详情、只读结果回看、导出和失败项重试。运行任务单独提示。快照保存原输入、知识库版本、模型元数据、逐题答案和来源；知识库替换或删除后仍可回看、导出。重试创建关联原任务的新执行，复制已完成项，不改写原任务。
- 增量索引按实际向量化文本的内容哈希复用同项目、同模型身份和规则的向量，仅计算新增、修改内容。删除或变为空答案的记录不进入新索引；复用向量指向新版本记录。发布经过查询校验和事务处理，失败/取消保留旧可用索引。同版本兼容重建后的索引允许原任务失败重试；版本、模型或范围不兼容仍拒绝。
- 网页及 Excel 的自评说明后依次增加依据、详细说明。依据只取“可直接复用、部分有依据、无相关信息、调用失败”；详细说明分别为 `/`、缺少依据的内容、`没有搜索到相关信息`、`调用失败`。缺失要求不再附在自评说明中。
- 真实输入原为 A–C 三列，导出 C 正文、D 依据、E 详细说明、F 来源。若原 D 起有附加列，原列右移两列，来源附在原有列之后。仅拆涉及问题的纵向 C 列合并，不覆盖源文件。

## 范围与限制

- 仅百炼进行了真实云端测试；其他服务商有配置与兼容入口，本轮未实测。
- 两条调用失败保留明确状态与重试入口；未通过无限重试或弱化证据校验消除失败。
- 来源片段、行号和文件映射核对证明数据一致，不证明模型对全部复合要求的覆盖判断都已人工确认。“无相关信息”表示本次候选与判断结果。
- 导出暂不支持宏、加密、受保护待填表、跨 C 合并、影响插列的 3D 公式，以及附加列与图表/结构化表组合等情况；不能把实际文件的保留验证推广为任意 Excel 功能的完整支持。
- Impeccable 机械检测运行一次，因解析模块缺失退化为正则扫描（DEGRADED），109 项 advisory；没有计算完整选择器或对比度。新列/布局末尾规则未新增检测项，视觉复核通过，不把降级检测称为全项自动通过。输出 `v14-detector.json`。
- 本轮使用 SQLite 在线备份保留原业务数据；服务运行于 `http://127.0.0.1:4173`。密钥未在聊天、报告、导出或任务快照中保存或显示。
