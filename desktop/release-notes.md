QSA-RAG Windows x64 桌面版。

0.7.0-beta.3 修复退出卡住：清理残留网页连接，等待后台保存完成后关闭数据库，并处理进程退出与 IPC 回包的时序。

0.7.0-beta.2 修复安装后启动失败：补齐 AI SDK 的 zod 运行依赖，并增加安装包依赖完整性检查及源码目录之外的验收。旧版 beta.1 请升级此版本。

- 内置 Node.js、Python 与 Excel 处理依赖，用户无需另外安装。
- 独立桌面窗口，业务数据保存在当前用户的应用数据目录。
- 支持通过 GitHub Releases 检查和下载更新；任务或文件正在处理时延后安装。
- 升级与卸载保留业务数据；同一 Windows 用户下继续使用已有 API Key。

带 `beta` 的版本为测试版。当前测试安装包未签名，Windows 可能显示发布者未知；正式图标和 Windows 签名将在正式发布前配置。

下载 `QSA-RAG-<版本>-win-x64-setup.exe` 安装。更新元数据和 `.blockmap` 供应用自动更新使用。
